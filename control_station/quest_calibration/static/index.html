先在 Quest 页面输入配对码并进入 MR/VR。确认 Quest 与左臂状态已连接后，回到启动终端：

  1. 按一次 r，保持当前姿态固定 3 秒；窗口会自动完成。

  3. 按 c 封存已完成窗口并执行 AX=XB 诊断解算。
