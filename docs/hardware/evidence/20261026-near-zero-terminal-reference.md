# 近零采集：参考完成与实测到位的交接

固定基线为 `86a9392fa0bbc43bcb4616740963b9d6b39011b6`。真机证据为远端
`near-zero-cruise-plateau-acceptance/b601-owner-iqbi30ql`；原始结果、报告和压缩
轨迹均保留。仅检查本硬件线，未修改框架工作区，也未再次驱动设备。

## 运行事实

- 完成 J2 前两段（第一段为非拟合摆位，第二段为训练），第三段反向运动超时；
  尚未进入 J3，因此不能据本轮声称 J3 速度配对已经改善。
- 第三段 17,824 个派发周期中，共享 1 N·m 包络饱和次数为 0。最后约十秒的
  J2 附加命令中位数为 -0.239 N·m，J3 为 -0.0646 N·m，不能归因于硬限幅。
- 最后一帧的 J2 目标与参考均为 0.01735987756 rad，参考速度为零；实测
  0.02109223604 rad，误差 -0.00373235848 rad，超过原 0.003375 rad 交接窗口。
  原生标签仍为 `track/bounded_reference_tracking`。
- 全程实际反馈、计算、发送频率均约 99.03 Hz；反馈没有超过 20 ms 的间隔，
  计算及发送各一次约 21 ms 间隔。此次主要阻塞不是发送频率。
- 软停止后回位路线完成，撤力／基础阻尼和静止确认完成；J2 原位偏差
  0.00536893262 rad 超过原 0.0045 rad 最终窗口，故没有自动失能。操作者后续
  中断，实际 motor disable、active-report disable、limits restore、transport close
  均已确认，清理无错误。不能把路线完成等同于完整自动回位失能。

## 因果边界与修复

上一轮让零速巡航不再退回位置积分，消除了停顿期间错误加力，但遗漏了参考轨迹
已经完成、实际关节仍未到位的情形。此时速度误差的稳态值为零，位置 PD 加保留
偏置仍可能不足以突破剩余静摩擦，控制器因而无限维持一个停在目标外的平衡。

本候选只在显式启用的巡航到位反馈中，把以下原生参考状态接入已有到位修正：
参考位置精确等于最终目标，且参考速度精确为零。途中参考暂停不是这个状态。
恢复使用原生已有的内侧刹停预留量，随后仍按原外侧容差和连续静止 dwell 交接；
不增加积分器、自动重试、时间、预算或新的保护阈值。原位撤力后的确认门仍保留。

速度窗口成熟之前仍保留确认偏置；成熟后复用现有可逆位移反馈、受限位置恢复、
最终限幅及完整派发提交。到位恢复不查询巡航前馈模型，也不进入巡航拟合。报告同时
识别原生标签仍为 TRACK 的历史终点记录，避免后续重处理把它们误判为恒速采集。

## 验证边界

新增 J2/J3 双向、原外侧窗口内外的停止短缺回归，并保留途中暂停、错误派发、
共享包络、影子模式和报告准入检查。终点粘滑声明模型使用同样初态和保护参数，
基线四组均在 15 秒内无法交接；候选四组约 2.23–2.27 秒完成原窗口与连续静止
交接。这是声明模型，未辨识真实惯量／摩擦，不能当作新的真机验收。

没有应用重力、摩擦或前馈拟合，没有扩大实际力矩／速度／位移、40 ms watchdog、
段时限、暴露预算或最终失能门。仍需新的近零真机单轮验证；当前局部采集没有足够的
独立正反向验证配对，不能据此推广补偿模型。
