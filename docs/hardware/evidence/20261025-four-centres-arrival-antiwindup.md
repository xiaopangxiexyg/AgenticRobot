# 四中心采集：到位反馈与积分抗饱和

基线为 `c64cd564c19d58aeaf502e292dd3ea2b1044e75b`，继承已完成近零采集的
`755fc41907bc22abfd5608e82bf86d5c4979404c`。四中心仍为 `(3,3)、(3,6)、
(6,6)、(6,3)` 度；J2 两速度，J3 三速度，计划 136 段。训练和验证使用独立试次。

基线真机批次 `four-centres-pairing-acceptance/managed-2d8u40q2` 完成 50 段，
在第二中心 J3 第三段超时；自动回位、失能和传输释放均完成。J3 主要在相邻两个
编码器计数间变化，目标误差约 0.0053 rad。实际发送约 98.89 Hz，原共享力矩上限
不是该段停滞的原因。193 个稳定运动窗口保留，报告尚未准许模型应用。

原到位更新同时累加 `-Kdisp * delta_q` 和位置误差积分，最终抗饱和却把两者都
当作积分增长。原生 PD 和窗口阻尼共同占用上升斜率时，返回计数的可逆反馈可能
被丢弃，出去的计数却被保留。候选先得到受偏置上限约束的可逆反馈基线，再针对
超出该基线的自适应增长执行原抗饱和。速度缩放、总限幅及其回算仍在最终门之前，
该门只能减少它们的结果，不重建被撤销的驱动力。

不改变巡航 PI、到位容差、驱动器阻尼、力矩/速度/位移限制、40 ms watchdog、
命令暴露预算、段时限、自动回位失能，也不修改或启用重力/摩擦拟合参数。
新增审计字段区分可逆反馈基线和自适应增量；偏置及位移观察仍只在匹配完整派发后提交。

复现使用原生位置 PD 和 80 ms 速度反馈，覆盖两个方向、7.5/10 ms 周期、目标带内
和停止在带外两种情形。旧代码在 7.5 ms 条件下复现偏置流失，候选通过。
对失败段 16,919 帧相同闭环输入的反事实回放，旧代码发生 730 次可逆增长丢失，
支撑偏置停留在约 0.09 N·m；候选能继续增加有效支撑并触及原总限幅。
该回放固定编码器和原生 PD 输入，不代表改变控制后真实机械臂仍会静止，
也不能作为真机改善或精确力矩辨识的验收。

J2 约 0.037 N·m，合计原 1 N·m 上限；位置尚差约 0.013 rad，最终命令暴露预算耗尽。
这次不能解释为到位抖动，扩大时间／暴露预算不会增加可用力矩。没有扩大原包络或

## 巡航反馈在粘滑平台上的控制权

以 `d45f336da786d7f514737a21c518c94052d86bb5` 为固定基线进一步检查上述同一条
真机记录。首个 J3 巡航的 12 秒减量记录包含 1,190 帧；窗口零位移、少于两个计数
或短暂反向时，原速度 PI 不执行，外层因此退回 `stationary_bias_refinement`。
位置参考仍在前进，这条位置误差积分比原速度积分增长快，使粘滑平台上增加的驱动力
在起步后保留下来。一次间断前后，记录偏置由约 0.30 增至 0.63 N·m。

候选只在已显式启用的巡航路径中，让因果窗口成熟后的零计数、反向运动和暂停参考
继续由同一个速度误差 PI 调节。因果窗口尚未成熟或参考确实指离目标时，保留已确认
偏置，不退回位置误差积分。拟合仍独立要求完整位移和运动学证据：控制器可以使用
零速反馈，不等于将它准入为滑动摩擦数据。到位反馈、非巡航位置移动、探针、回位、
共享控制入口和所有限幅／保护参数均未修改。

固定同一组位置、原始速度与原生跟踪帧，使用旧／新完整合成器分别提交其自己的
派发回执：旧逻辑有 511 帧位置积分回退，候选为 0；累计正向偏置增量从 1.239 降为
0.707 N·m，最大偏置幅度从 0.661 降为 0.241 N·m。这是固定输入反事实，改变控制
后真实位置不会仍按这条轨迹变化，不能据此宣称真机速度已经改善。

另以相同初始条件、力矩／速度包络进行四组声明粘滑模型比较。四组均到位，三组巡航
速度 RMS 误差下降约 12%–30%，一组相同；其中一组起步速度峰值略增
0.03232→0.03278 rad/s。模型没有按本机辨识，结果仅支持回归与候选比较，不能代替
新真机验收；末段真实 1 N·m 饱和和最终原位窗口问题仍单独保留。

首次扩大回归为 603 通过、1 个前馈效果断言失败，原记录保留。该用例原本要求实验性
command field 在四个声明模型工况中逐个严格改善。速度控制修正后，正向 0.015 rad/s
工况的无前馈基线改善到 0.000471 rad/s，而原前馈为 0.000511 rad/s；不是超速、
到位或派发失败。比较测试现在显式保留三组改善、一组不改善的反例，并继续要求所有
原到位／速度包络和影子模式与无前馈的精确一致性。没有修改前馈系数或放宽误差门；
这组旧前馈不获得应用或推广资格，下一轮仍只运行 shadow。
