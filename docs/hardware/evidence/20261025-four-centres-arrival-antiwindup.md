# 四中心采集：到位反馈与积分抗饱和

基线为 `c64cd564c19d58aeaf502e292dd3ea2b1044e75b`，继承已完成近零采集的
`755fc41907bc22abfd5608e82bf86d5c4979404c`。四中心仍为 `(3,3)、(3,6)、
(6,6)、(6,3)` 度；J2 两速度，J3 三速度，计划 136 段。训练和验证使用独立试次。

基线真机批次 `four-centres-pairing-acceptance/managed-2d8u40q2` 完成 50 段，
在第二中心 J3 第三段超时；自动回位、失能和传输释放均完成。J3 主要在相邻两个
编码器计数间变化，目标误差约 0.0053 rad。实际发送约 98.89 Hz，原共享力矩上限
不是该段停滞的原因。193 个稳定运动窗口保留，报告尚未准许模型应用。

原到位更新同时累加 `-Kdisp * delta_q` 和位置误差积分，最终抗饱和却把两者都
当作积分增长。原生 PD 和窗口阻尼共同占用上升斜率时，返回计数的可逆反馈可能
被丢弃，出去的计数却被保留。候选先得到受偏置上限约束的可逆反馈基线，再针对
超出该基线的自适应增长执行原抗饱和。速度缩放、总限幅及其回算仍在最终门之前，
该门只能减少它们的结果，不重建被撤销的驱动力。

不改变巡航 PI、到位容差、驱动器阻尼、力矩/速度/位移限制、40 ms watchdog、
命令暴露预算、段时限、自动回位失能，也不修改或启用重力/摩擦拟合参数。
新增审计字段区分可逆反馈基线和自适应增量；偏置及位移观察仍只在匹配完整派发后提交。

复现使用原生位置 PD 和 80 ms 速度反馈，覆盖两个方向、7.5/10 ms 周期、目标带内
和停止在带外两种情形。旧代码在 7.5 ms 条件下复现偏置流失，候选通过。
对失败段 16,919 帧相同闭环输入的反事实回放，旧代码发生 730 次可逆增长丢失，
支撑偏置停留在约 0.09 N·m；候选能继续增加有效支撑并触及原总限幅。
该回放固定编码器和原生 PD 输入，不代表改变控制后真实机械臂仍会静止，
也不能作为真机改善或精确力矩辨识的验收。
